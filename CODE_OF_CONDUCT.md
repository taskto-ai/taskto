# Code of Conduct

taskto.ai follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in the project's spaces (the repository, its issues, pull requests
and discussions, and any chat or event in the project's name) agrees to it.

In short: be welcoming, considerate and respectful; accept that people differ in
experience and opinion; give and take criticism of the work, not of the person; and don't
harass, insult or publish anyone's private information.

## Reporting

If someone's behaviour breaks the Code of Conduct, report it privately to the project's
maintainers, at the contact address on the GitHub organisation's profile page. Don't use a
public issue. Reports are kept confidential, and the maintainers will review each one and
respond as the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
describe: from a private correction to a permanent ban.
